About Shift Requirements

These requirements define the minimum and maximum number of nurses and RAs needed for each shift type.

  • Min/Max Nurses: The minimum and maximum number of nurses required per shift
  • Min/Max RAs: The minimum and maximum number of resident assistants required per shift
  • Max Total Staff: The total number of staff members (nurses + RAs) allowed per shift

These settings will be used when generating the rota schedule.
