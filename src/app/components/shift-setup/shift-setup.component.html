About Shift Requirements

These requirements define the minimum and maximum number of nurses and RAs needed for each shift type.

  • Min/Max Nurses: minimum and maximum number of nurses required per shift
  • Min/Max RAs: minimum and maximum number of resident assistants required per shift
  • Max Total Staff: total number of staff members allowed per shift

These settings are used when generating the rota schedule.
